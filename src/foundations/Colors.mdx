# Colors

The color palette from the SuperConscious design system. Every color is available as a CSS custom property in `src/styles/colors.css` — click any swatch to copy its `var(...)`.

**LM** marks the light-mode version of a color and **DM** the dark-mode version. Translucent colors are shown over a checkerboard so you can see their opacity.
