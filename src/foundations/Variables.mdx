# Variables

Every variable from the SuperConscious Figma file, available in code as CSS custom properties from `src/styles/variables.css`. Click a variable name to copy its `var(...)`.

Variables that point to another variable (an alias in Figma) show the name they point to, with the final value underneath. The raw palette they point to is on the [Colors](?path=/docs/foundations-colors--docs) page.

## Semantic Colors

These change with the theme: the Light values apply by default and the Dark values when the page has `data-theme="dark"` (the Theme switch in the toolbar).
