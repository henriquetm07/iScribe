# iScribe

The component library for iScribe, built with React, TypeScript and Storybook.

## Components

- **Button** — six variants, six sizes, square or rounded, with optional icons
- **Icon Button** — icon-only, square or circle, same styles as the Button
- **Dropdown** — a field (Web, iPhone, iPad) that opens a **Selection List** of options when active
- **Selection List** — a card of selectable rows (iPhone, iPad, Web) with one selected value, hover, destructive rows and a scroller; its rows are **Selection List Items**
- **Bottom Tab** — the bar at the bottom of the iOS screen (iPhone and iPad): slide to send + Review, an alert, or an alert with a button. Built from the Button, Icon Button and Icons
- **Web Nav Bar** — the top bar of the web app: logo, menu, Chrome extension, practice Dropdown, avatar, search and connectivity. When the bar is too narrow, the menu compacts into a button that opens a **Selection List**

## Icons

63 icons from the Figma icon page, drawn with `currentColor`: `<Icon name="trash" size={16} />`. See **Foundations / Icons**.

Animated icons are Lottie (JSON) animations on the same grid: `<AnimatedIcon name="arrow-to-check" />`. See **Foundations / Animated Icons**.

## Design tokens

Colors, spacing, radii and fonts live in `src/styles/tokens.css` as CSS custom properties prefixed `--is-`.
Components read from these tokens, so changing a value there restyles the whole library.
